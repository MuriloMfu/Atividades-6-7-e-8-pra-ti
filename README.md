 Exercício 1 — Sistema de Biblioteca em Java (POO)

Sistema de gerenciamento de acervo e empréstimos utilizando os pilares da Programação Orientada a Objetos (Encapsulamento, Herança e Polimorfismo).

 Tecnologias e Conceitos Aplicados
*Java*
*Abstração e Herança:* Classes abstratas "ItemBiblioteca" e "Usuario" estendidas por suas respectivas subclasses concretas.
*Polimorfismo:* Regras de prazo, multa e limites tratadas dinamicamente sem o uso de condicionais de checagem de tipo.


Compilar os arquivos

javac br/com/biblioteca/model/*.java br/com/biblioteca/service/*.java br/com/biblioteca/Main.java

Executar a aplicação

java br.com.biblioteca.Main
